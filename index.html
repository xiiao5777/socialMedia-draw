每台電腦、每個瀏覽器只要裝一次。請用電腦版的 Chrome、Edge、Safari 或 Firefox，手機不能裝。

已經裝過舊版的話：在書籤列的「抓取抽獎名單」上按右鍵，選「刪除」，再用下面的方法一重新拖一次。打開工具時，標題旁邊顯示「v1.2」就是新版。

方法一：拖到書籤列 最快

  1. 先讓書籤列顯示出來：在 Chrome 或 Edge 按 Ctrl + Shift + B，Mac 按 ⌘ + Shift + B。網址列下面會多出一條橫列。

  2. 用滑鼠按住紅色的「抓取抽獎名單」按鈕不放，拖到書籤列上再放開。動畫示範了整個過程。

抓取抽獎名單

拖這個按鈕。書籤列出現「抓取抽獎名單」就裝好了。直接點它不會有反應，要用拖的。

方法二：複製程式碼 拖不動時用

  1. 按這個按鈕複製程式碼：

  2. 在 Chrome 按 Ctrl + Shift + O（Mac 按 ⌘ + Option + B）打開書籤管理員，點右上角的「⋮」，選「新增書籤」。Edge 的步驟類似，在「我的最愛」裡新增。

  3. 名稱填「抓取抽獎名單」，網址那一欄貼上剛剛複製的程式碼，按「儲存」。

使用教學

抓完都是按「複製結果」，再到抽獎系統第 1 步貼上，按「加入名單」。留言、按讚、分享要分開抓、分開貼，同一個人會自動合併。

抓名單

Facebook

留言

  1. 打開那一則貼文。在動態上的話，先點貼文上的時間，進到單一貼文。

  2. 按書籤列的「抓取抽獎名單」。工具會把排序改成「所有留言」，並自動展開全部留言和回覆。

  3. 跑完後按「複製結果」。

按讚和分享

點貼文下方的心情數字（或「X 次分享」）打開名單視窗，再按一次書籤。

X

回覆

  1. 點進那一則貼文，網址會有 /status/。

  2. 按書籤，工具會往下捲動讀取所有回覆。你自己的回覆會自動略過。

  3. 跑完後按「複製結果」。

按讚、轉發、引用

點貼文的按讚數或轉發數打開名單頁（網址結尾是 /likes、/retweets 或 /quotes），再按一次書籤。X 只讓貼文作者看到按讚名單。

Threads

回覆

  1. 點進那一則貼文，網址會有 /post/。

  2. 按書籤，工具會往下捲動讀取所有回覆。你自己的回覆會自動略過。

  3. 跑完後按「複製結果」。

按讚和轉發

點貼文下方的讚數或「動態」打開名單視窗，再按一次書籤。

抽獎

  1. 匯入參加者把複製的結果貼到第 1 步，按「加入名單」。也可以直接貼名字，或匯入 CSV 檔。

  2. 參加條件勾選要留言、按讚、分享、標記幾位好友、包含關鍵字，也能排除小編。參加者名單會標出誰符合資格。

  3. 獎品設定每個獎項的名稱和名額。

  4. 抽獎台按「抽出 1 位」。抽出的人會移出抽獎池，不會重複中獎。可以開全螢幕給大家看。

  5. 得獎名單「複製得獎公告」貼到貼文，「下載 CSV 紀錄」留存。聯絡不上的得獎者可以作廢再補抽。

開始抽獎

第一次打開會有範例資料，可以先試抽；按「清除範例，開始使用」就換成你的名單。

常見問題

要付費或登入嗎？

不用。整個網站免費，不用註冊、不用登入，也不用給任何帳號權限。抓取工具只讀你自己畫面上看得到的名單。

抽獎資料存在哪裡？

存在你這台電腦的瀏覽器裡，不會上傳到任何伺服器。換電腦、換瀏覽器、用無痕視窗或清除瀏覽資料，就看不到之前的抽獎了，抽完記得「下載 CSV 紀錄」或「複製得獎公告」保存。

要辦下一次抽獎怎麼做？

抽獎系統一次保存一場抽獎。先把這次的結果下載 CSV 保存，再到得獎名單下面按「清除全部資料」，就能從第 1 步重新開始。

抽獎公平嗎？

抽獎用瀏覽器內建的密碼學亂數，每位符合資格的人機會都一樣。同一個人留言很多次也只算一次，抽出的人會移出抽獎池。每次抽出都會記下時間和當時抽獎池人數，CSV 紀錄裡都有。

抓的時候可以切到別的分頁嗎？

請不要。瀏覽器會把背景分頁放慢，工具可能停住或抓不完整。留言很多時要等幾分鐘，跑完會顯示「複製結果」按鈕。

抓到 0 則或數量不對怎麼辦？

先確認打開的是單一貼文，按讚或分享名單要先點開名單視窗再按書籤。還是不對的話，按工具上的「複製診斷資訊」，連同哪個平台一起回報問題。

名單會被傳到別的地方嗎？

不會。工具只讀你畫面上的內容（頭像會從同一個網站的圖片伺服器再讀一次，用來縮小），結果複製到你自己的剪貼簿，由你貼到抽獎系統，不會傳到其他伺服器。

有些頭像沒抓到？

有的網站不讓其他網頁讀取圖片。抓不到的人，在抽獎系統會用名字的第一個字代替，不影響抽獎。工具跑完會顯示「頭像 幾 / 幾 張」。

手機可以用嗎？

抓取工具要在電腦的瀏覽器上用。抽獎頁手機也打得開，但資料存在各自的瀏覽器裡，電腦上的抽獎不會出現在手機上。

怎麼知道工具有沒有更新？

工具面板的標題旁邊會顯示版本（現在最新是 v1.2）。把抓取結果貼到抽獎系統時，如果用的是舊版，抽獎系統會跳出提醒，告訴你怎麼更新。

Facebook、X 或 Threads 改版後不能用了？

請回報問題，修好後會更新工具。更新後要刪掉舊的「抓取抽獎名單」書籤，再照上面的步驟裝一次。
